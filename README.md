## ✨ المميزات

| الميزة | الوصف |
|:------:|-------|
| 🔍 | **فحص بلا أثر جانبي** — يقرأ الترويسات فقط ولا يعلّم رسائلك كمقروءة |
| ☑️ | **قائمة مراجعة** — تشوف كل رسالة ودرجتها وسبب ترشيحها، وتختار بنفسك |
| 🗂️ | **نقل بدل محو** — الافتراضي نقل إلى مجلد مراجعة قابل للتراجع |
| 📊 | **درجة اشتباه مفسَّرة** — لا قرار ثنائي غامض، بل درجة وأسباب مقروءة |
| 🚫 | **إلغاء اشتراك بالمعيار** — POST وفق RFC 8058، أو رسالة `mailto` الأأمن |
| 🛡️ | **فحص الروابط قبل زيارتها** — HTTPS فقط، ولا عناوين داخلية |
| 📄 | **تصدير JSON** — بلا روابط حساسة ما لم تطلبها صراحةً |
| 🌐 | **متعدد المزوّدين** — Gmail وOutlook وYahoo وiCloud وأي خادم IMAP |

## 📋 المتطلبات

- **Python 3.9** أو أحدث
- **Tkinter** (مدمجة مع بايثون؛ على دبيان/أوبونتو: `sudo apt install python3-tk`)
- **requests** — اختيارية، لميزة إلغاء الاشتراك بنقرة واحدة فقط

### 📝 خطوات الاستخدام

```
1️⃣ أدخل البريد وكلمة المرور، ثم Enter أو «اتصال»
2️⃣ حدد عدد الأيام والحد الأقصى للرسائل
3️⃣ اضغط «فحص» (أو F5)
4️⃣ راجع القائمة: كل رسالة ودرجتها وسبب ترشيحها
     • الرسائل بدرجة 4 فأعلى محدَّدة تلقائيًا
     • انقر على ☑ لتغيير أي تحديد
5️⃣ اختر الإجراء:
     🗂️ معالجة المحدد  — نقل إلى مجلد مراجعة، أو حذف نهائي
     🚫 إلغاء الاشتراك  — بالطريقة الأأمن المتاحة لكل مرسل
     📄 تصدير           — تقرير JSON
```

## 🧠 كيف يعمل التصنيف

الأداة **لا تعطي قرارًا ثنائيًا**، بل درجة اشتباه مع أسباب تُعرض لك:

| الإشارة | الدرجة |
|---|:---:|
| وجود ترويسة `List-Unsubscribe` | +2 |
| `Precedence: bulk / list / junk` | +2 |
| كلمة دعائية في **الموضوع** (بحدود كلمات) | +1 |
| مرسل متكرر (5 رسائل فأكثر) | +1 |
| الجزء المحلي يشبه بريد معاملات (`billing@`, `security@`) | −2 |
| نطاق موثوق (`google.com` مثلًا) | إعفاء كامل |

**العتبات:** الرسالة تظهر في القائمة عند الدرجة **3**، وتُحدَّد تلقائيًا عند **4**.

> ترويسة `List-Unsubscribe` وحدها لا تكفي — تضعها إشعارات GitHub وكشوف البنوك
> وقوائم بريد العمل. وحدود الكلمات تمنع مطابقة `sale` داخل `sales@` أو
> `wholesale`، فلا تُصنَّف رسالة «Job Offer» كدعاية.

## 🔒 الأمان والخصوصية

| الجانب | السلوك |
|---|---|
| كلمة المرور | لا تُخزَّن ولا تُكتب على القرص، وتُمسح من الذاكرة فور نجاح الدخول |
| الاتصال | `IMAP4_SSL` مع تحقق كامل من الشهادة واسم المضيف |
| روابط إلغاء الاشتراك | HTTPS فقط، وتُرفض العناوين الداخلية (`127.0.0.1`, `192.168.x.x`, `169.254.169.254`) |
| إعادة التوجيه | لا تُتَّبع تلقائيًا؛ كل قفزة تُفحص، وبحد أقصى قفزتان |
| الروابط غير الآمنة | لا تُزار إطلاقًا — تُعرض لك لتقرر بنفسك |
| ملف التصدير | بلا روابط افتراضيًا (قد تعمل كرموز وصول لحسابك لدى المرسلين) |

### لماذا `mailto` أفضل من الرابط؟

ترويسة `List-Unsubscribe` كثيرًا ما تحمل عنوان `mailto:` إضافةً إلى الرابط.
إرسال رسالة إلغاء اشتراك **لا يكشف عنوان IP الخاص بك ولا يزور خادمًا يتحكم به
المرسل**، بينما زيارة الرابط تفعل الاثنين — وتؤكد لمرسلي الرسائل المزعجة أن
عنوانك حيّ ومقروء. لذلك ترتيب الأفضلية في الأداة:

```
نقرة واحدة (RFC 8058)  ←  رسالة mailto  ←  يدوي (نعرض الرابط ولا نزوره)
```

## 🛠️ البنية التقنية

```
Email-Cleaner-Tool/
├── email_cleaner/
│   ├── __main__.py     # نقطة الدخول: python -m email_cleaner
│   ├── models.py       # أنواع البيانات
│   ├── rules.py        # تحميل القواعد ومطابقتها
│   ├── rules.json      # القواعد الافتراضية (بيانات لا كود)
│   ├── netsafe.py      # فحص سلامة الروابط
│   ├── parsing.py      # تحليل الترويسات والتسجيل بالدرجات
│   ├── core.py         # محرك IMAP
│   └── gui.py          # الواجهة الرسومية
├── tests/              # 119 اختبارًا، بلا شبكة
└── pyproject.toml
```

| الوحدة | المسؤولية |
|---|---|
| `core.EmailCleanerCore` | IMAP، الفحص، النقل/الحذف، إلغاء الاشتراك، التصدير |
| `parsing` | دوال نقية على `email.message.Message` — قابلة للاختبار بالكامل |
| `netsafe` | البوابة الوحيدة التي تمرّ منها الروابط قبل أي طلب |
| `gui.EmailCleanerGUI` | العرض فقط — لا يعرف شيئًا عن IMAP |

## 🔧 التخصيص

القواعد **بيانات لا كود**. ضع تعديلاتك في `~/.email_cleaner/rules.json` وستُدمج
فوق الافتراضيات، فيبقى تخصيصك سليمًا بعد تحديث الأداة:

```json
{
  "imap_servers": {
    "yourdomain.com": ["imap.yourdomain.com", 993]
  },
  "promotional_keywords": ["كلمتك الخاصة"],
  "thresholds": { "include": 3, "auto_select": 5 }
}
```

> المفاتيح غير المذكورة تبقى على قيمها الافتراضية. ملف تالف يُتجاهل بلا
> منع تشغيل الأداة.

## ❓ الأسئلة الشائعة

<details>
<summary><b>لماذا يفشل تسجيل الدخول؟</b></summary>

- استخدم **كلمة مرور التطبيق** لا كلمة مرور الحساب (خاصة مع Gmail وYahoo)
- تأكد من تفعيل IMAP في إعدادات بريدك

</details>

<details>
<summary><b>هل الفحص يغيّر شيئًا في صندوقي؟</b></summary>

لا. الفحص يقرأ الترويسات فقط عبر `BODY.PEEK`، فلا يعلّم رسائلك كمقروءة ولا
ينزّل المرفقات. التغيير الوحيد يحدث عند ضغطك «معالجة المحدد».

</details>

<details>
<summary><b>هل يمكن التراجع عن الحذف؟</b></summary>

الوضع الافتراضي **نقل** إلى مجلد `Email Cleaner/Review` — الرسائل تبقى وتقدر
ترجعها متى شئت. الحذف النهائي خيار صريح لازم تختاره بنفسك، وهو **لا رجعة فيه**.

</details>

<details>
<summary><b>ماذا يحدث عند إلغاء الاشتراك؟</b></summary>

الأداة تستخدم أأمن وسيلة متاحة لكل مرسل، وتقول لك بصراحة ما الذي حدث فعلًا.
لا تدّعي نجاحًا لم يتأكد: الرابط الذي لا يعلن دعم النقرة الواحدة يُعرض لك
لتفتحه بنفسك بدل زيارته نيابةً عنك.

</details>

<details>
<summary><b>هل الأداة آمنة؟</b></summary>

- ✅ لا تخزّن كلمات المرور ولا تكتبها على القرص
- ✅ الاتصال مشفّر مع تحقق كامل من الشهادة
- ✅ لا تزور أي رابط لا يجتاز فحص السلامة
- ✅ الكود منشور بالكامل ويمكنك مراجعته سطرًا سطرًا

</details>
